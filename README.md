## 修改内容

- 本地音频导入与播放：支持微信「打开方式 / 分享到 BBPlayer」与应用内文件选择，保留原文件名，导入到本地音乐页
- 喜马拉雅播客订阅：粘贴喜马拉雅分享链接即可订阅专辑，自动创建同名歌单并导入最近单集（解析官方下载直链，支持直接播放）
- 播客歌单「更新单集」按钮：重新拉取专辑最新单集并替换歌单内容（保留最新 20 条）
- 界面自定义：底部导航栏可隐藏「搜索 / 我的」等；移除「稍后再看」与账号登录入口
